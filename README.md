# Vision-Link AI HUB — Frontend

A real-time monitoring dashboard for the Vision-Link multi-agent healthcare AI pipeline.

## Tech Stack
- **React + Vite** — Fast, modern frontend framework
- **Tailwind CSS** — Utility-first styling
- **JetBrains Mono + Space Mono** — Monospace fonts for clinical/terminal aesthetic

## Components

| Component | Description |
|---|---|
| `AgentLogs` | Live scrolling logs for Clinical Agent and Validation Agent |
| `LLMBadge` | Dynamic model indicator — shows Llama-3-8B or Mistral-7B active status |
| `JsonViewer` | Structured cards and raw JSON view for LangGraph pipeline payloads |
| `StatusBar` | Top-level pipeline metrics bar |

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
